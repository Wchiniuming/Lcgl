# Lcgl 理财管家 多维度优化迭代方向与落地计划

### 维度 1：用户体验（UX）深度优化（核心优先级）

#### 核心痛点

现有功能模块清晰，但操作流程冗余、新手门槛高、可视化交互单一、无个性化定制。

#### 借鉴标杆

薄荷记账（简洁交互）、MoneyWiz（沉浸式资产管理）、同花顺（可视化体验）

|迭代阶段|具体优化点|技术实现路径|可行性保障|
|---|---|---|---|
|V1\.1|1\. 新手引导体系<br>\- 首次使用分步引导（创建账户→分类→首笔交易）<br>\- 空状态智能提示（无账户 / 无交易时展示引导卡片）<br>2\. 操作流程简化<br>\- 交易录入：合并 “模板交易 \+ 快速记账”，支持拖拽复用模板<br>\- 批量价格更新：新增 Excel 粘贴导入 \+ 操作预览（防误改）<br>3\. 可视化升级<br>\- 仪表盘：新增 “收支日历视图”<br>\- 持仓分布：3D 饼图 / 环形图切换、按风险 / 收益区间筛选<br>4\. 交互细节<br>\- 表单自动保存（localStorage \+ 数据库临时表）<br>\- 快捷键支持（Ctrl\+S 保存 / Ctrl\+N 新建）<br>\- 提示优化（Toast 位置 / 时长自定义、确认弹窗 “下次不提示”）|\- 前端：React Router 懒加载 \+ 空状态组件开发<br>\- ECharts 扩展配置（自定义图表类型、筛选逻辑）<br>\- Tauri 调用系统剪贴板 API 实现 Excel 粘贴|\- 无新增技术栈，基于现有 React/ECharts/Tauri 能力<br>\- 先落地 “新手引导 \+ 表单自动保存”2 个轻量功能，验证用户反馈|
|V1\.2|1\. 个性化定制<br>\- 浅色 / 深色 / 自定义主题（适配系统级深色模式）<br>\- 桌面端悬浮快捷面板（快速记账 / 仪表盘 / 提醒）<br>2\. 筛选与导出优化<br>\- 多条件组合筛选（支持保存常用筛选方案）<br>\- 导出文件自定义字段（如持仓导出可选 “成本 / 盈亏 / 收益率”）|\- 前端：Tailwind CSS 主题变量配置<br>\- Tauri 系统托盘 API 实现悬浮面板<br>\- 后端：SQL 动态拼接筛选条件（防注入）|\- 主题切换为前端纯样式改造，无后端依赖<br>\- 筛选方案保存复用现有 settings 表（JSON 存储）|
|V2\.0|1\. 无障碍适配<br>\- 高 DPI 屏幕适配（响应式布局优化）<br>2\. 交互动效升级<br>\- 页面过渡 / 组件加载动效（不影响性能）|\- 前端：React A11y 规范落地<br>\- Tauri 窗口缩放适配 API|\- 动效优先采用 CSS 实现，避免 JS 性能损耗<br>\- 无障碍适配分批次落地（先核心页面）|
