## 二、数据模型 (11张表)

### 2.1 核心实体关系

```
┌─────────────────┐      ┌─────────────────┐
│account_category │      │    accounts     │
│   (分类)        │──1:N─│    (账户)       │
└─────────────────┘      └────────┬────────┘
                                  │
                    ┌─────────────┼─────────────┐
                    │             │             │
                    ▼             ▼             ▼
            ┌───────────┐ ┌───────────┐ ┌───────────┐
            │transactions│ │ holdings  │ │reminders  │
            │  (交易)   │ │  (持仓)   │ │  (提醒)   │
            └───────────┘ └─────┬─────┘ └───────────┘
                                │
                                ▼
                        ┌───────────┐
                        │  prices   │
                        │  (价格)   │
                        └───────────┘
```

### 2.2 表详细说明

| 模块 | 表名 | 主键 | 说明 |
|------|------|------|------|
| **分类** | account_categories | id | 资产/负债分类，树形结构(parent_id) |
| **账户** | accounts | id | 资产/负债账户，含利率/期限/到期日 |
| **交易** | transactions | id | 收支/转账/调整，含附件路径 |
| **持仓** | holdings | id | 股票/基金/债券/理财/贵金属，含成本/盈亏 |
| **价格** | prices | id | 历史价格，symbol+date唯一索引 |
| **模板** | templates | id | 常用模板，use_count统计使用次数 |
| **快照** | snapshots | id | 财务快照(manual/auto/monthly/yearly) |
| **提醒** | reminders | id | 6种类型，支持重复提醒 |
| **保险** | insurances | id | 保单管理，含续保提醒 |
| **设置** | settings | key | 键值对配置(JSON存储) |
| **审计** | audit_log | id | 操作审计日志 |

### 2.3 持仓类型枚举

```
stock          - 股票
fund           - 公募基金
bond           - 债券
bank_financial - 银行理财
precious_metal - 贵金属
other          - 其他
```

### 2.4 账户分类 (种子数据)

**资产类**
- 流动资产: 活期存款, 定期存款, 现金, 应收账款
- 固定资产: 房产, 车辆, 贵重物品
- 金融资产: 股票, 公募基金, 银行理财, 债券, 国债, 贵金属, 私募基金, 期货

**负债类**
- 长期负债: 房贷, 车贷, 经营贷, 教育贷款
- 短期负债: 信用卡, 消费贷, 网贷, 应付账款

### 3.2 页面详细说明

#### 3.2.1 财务仪表盘 (Dashboard)

**路由**: `/` (默认首页)

**核心功能**:
- 总资产/负债/净资产卡片展示
- 资产趋势图 (可切换: 3M/6M/1Y)
- 账户健康度指标
- 费用追踪分析
- 快捷操作入口

**技术实现**:
- ECharts 折线图/柱状图
- Snapshot 快照数据
- React Router useLocation

#### 3.2.2 资产负债 (Accounts)

**路由**: `/accounts`

**核心功能**:
- 账户列表 (资产/负债分类)
- 账户 CRUD 操作
- 账户归档功能
- 财务快照 (手动创建/自动创建)
- 模板快捷交易
- 批量导入账户

**关键组件**:
- `QuickEntryModal` - 快速记账
- `Snapshot` - 快照管理

#### 3.2.3 投资组合 (Portfolio)

**路由**: `/portfolio`

**核心功能**:
- 持仓列表 (股票/基金/债券/银行理财/贵金属)
- 持仓 CRUD 操作
- 买卖记录追踪
- **批量价格更新** (支持5位小数精度)
- 定投计划 (SIP) 管理
- 持仓归档历史查看
- 持仓分布可视化

**关键组件**:
- `HoldingForm` - 持仓表单
- `SipPlan` - 定投计划

#### 3.2.4 保险管理 (Insurance)

**路由**: `/insurance`

**核心功能**:
- 保单 CRUD
- 续保日期提醒 (自动生成提醒)
- 状态追踪 (生效/失效/退保/理赔)
- 保单 PDF 文档关联

**保险类型**:
- 寿险, 医疗险, 意外险, 重疾险, 车险, 年金险, 其他

#### 3.2.5 投资看板 (InvestmentDashboard)

**路由**: `/investment-dashboard`

**核心功能**:
- 持仓分布饼图
- 收益趋势图
- 资产类别分析
- 盈亏统计

#### 3.2.6 收益分析 (ProfitAnalysis)

**路由**: `/profit-analysis`

**核心功能**:
- IRR (内部收益率) 计算
- 持仓收益率分析
- 历史业绩对比
- 费用分析

#### 3.2.7 提醒中心 (Reminders)

**路由**: `/reminders`

**核心功能**:
- 待处理提醒列表
- 6种提醒类型:
  - `account_update` - 账户更新提醒
  - `payment_due` - 还款提醒
  - `loan_due` - 贷款到期提醒
  - `investment_due` - 投资到期提醒
  - `insurance_renewal` - 保险续保提醒
  - `custom` - 自定义提醒
- 重复提醒设置 (日/周/月/年)
- 提前提醒天数配置
- 关联账户/持仓

#### 3.2.8 导入导出 (ImportExport)

**路由**: `/import-export`

**核心功能**:
- **Excel 批量导入** (支持账户/持仓/交易)
- JSON 数据导出 (全量备份)
- JSON 数据导入 (恢复)
- 导入向导 (`ExcelImportWizard` 组件)

#### 3.2.9 规划中心 (Planning)

**路由**: `/planning`

**核心功能**:
- 理财目标设定 (目标金额/日期)
- 风险评级 (1-5级)
- **智能再平衡建议** (根据当前持仓 vs 目标配置)
- 资产配置规划
- 版本历史追踪

**风险配置映射**:
| 风险等级 | 股票 | 基金 | 债券 | 银行理财 | 贵金属 |
|---------|------|------|------|---------|-------|
| 1 (最低) | 5% | 15% | 50% | 30% | 0% |
| 2 (低) | 15% | 20% | 40% | 25% | 0% |
| 3 (中) | 35% | 25% | 25% | 10% | 5% |
| 4 (高) | 50% | 25% | 15% | 5% | 5% |
| 5 (最高) | 60% | 20% | 10% | 0% | 10% |

#### 3.2.10 系统设置 (Settings)

**路由**: `/settings`

**核心功能**:
- **密码保护** (ARGON2 加密)
- 自动备份配置
- 备份目录管理
- 手动创建备份
- 备份恢复
- 旧备份清理

#### 3.2.11 登录 (Login)

**路由**: `/login` (未认证时)

**核心功能**:
- 密码验证 (ARGON2)
- 登录失败锁定 (5次/15分钟)
- 首次使用设置密码
- 忘记密码提示
